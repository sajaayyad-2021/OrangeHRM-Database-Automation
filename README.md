# OrangeHRM Test Automation - Database-Driven

## What Changed?

Migrated from file-based test data to **MySQL database architecture**.

### Before:
- Test data stored in JSON files
- Results saved in text files
- Manual file management

### After:
- ✅ All test data in MySQL database
- ✅ Test results tracked in database
- ✅ Centralized test management
- ✅ Easy reporting and analytics

## Tech Stack

- Java 21
- Selenium 4.36.0
- TestNG 7.9.0
- MySQL 8.0.33
- Maven
